# Sistema de Costos - Diseño Gráfico

Sistema web para calcular costos y ganancias de trabajos personalizados (vinil, letreros, etc.)

## Funcionalidades
- Gestión de materiales
- Cálculo de costos
- Registro de trabajos

## Tecnologías
- PHP
- PostgreSQL
- Bootstrap

## Cómo usar
1. Importar database/schema.sql
2. Configurar config/db.php
3. Ejecutar en servidor local
